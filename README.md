# ai-rescue
Aplicación de ayuda en situaciones de desastre, funciona completamente sin internet, usa solo IA local (QVAC) corriendo en el propio dispositivo.  Funciones principales  Traducción en tiempo real: escucha por el micrófono, transcribe lo que dice la persona, lo traduce y lo organiza de manera estructurada, actualiza con otros dispositivos cercanos
